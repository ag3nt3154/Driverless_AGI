---
name: grill-me
description: Interview the user relentlessly about a plan or design to stress-test their thinking. Use when user wants to explore a design, get grilled on their idea, or mentions "grill me".
---

Interview me relentlessly about every aspect of this subject. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one. For each question, provide your recommended answer.

**CRITICAL: You MUST use the `AskUserQuestion` tool for every question. Ask exactly one question per turn. Never ask multiple questions in a single message.**

Do NOT assume the goal is to produce a plan. The purpose of this skill is interrogation and stress-testing only. Only move to planning if the user explicitly asks for it.

If a question can be answered by exploring the codebase, explore the codebase instead of asking.
