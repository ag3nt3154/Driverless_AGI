It's the reserve, not the window. Compaction fires when the estimated prompt crosses

$$T = W - R - S = 200{,}000 - 48{,}000 - 12{,}400 \approx 139{,}600$$

where \(W\) is the context window, \(R\) = reserve_tokens and \(S\) is the system prompt. So you only get about 70% of the window for history.
