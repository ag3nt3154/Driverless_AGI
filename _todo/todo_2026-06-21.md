## A. Bugs & Critical Issues

### A1. `_handle_complete_plan` still uses `Path(__file__).parent.parent` instead of `DAGI_ROOT` (Priority: HIGH)

**File:** [`agent/loop.py:677`](agent/loop.py:677)

The `DAGI_ROOT` centralisation commit (`cdf90a8`) replaced 4 independent `Path(__file__).parent.parent` uses — but missed a 5th one inside `_handle_complete_plan`:

```python
def _handle_complete_plan(self) -> str:
    cleared = self.config.active_plan_file
    self.config.active_plan_file = None
    self._rebuild_for_normal_mode(Path(__file__).parent.parent)  # ← MISSED
    return ...
```

Compare with `_handle_exit_plan_mode` (line 654) and `_handle_enter_plan_mode` (line 609), which correctly use `dagi_root = DAGI_ROOT`.

**Impact:** Same fragility as the original: moving `loop.py` to a different depth would silently break. Also inconsistent with every other call site now using `DAGI_ROOT`.

**Fix:**
```python
self._rebuild_for_normal_mode(DAGI_ROOT)
```
